Passer d'une **supervision réactive** (les utilisateurs vous appellent) à une approche **proactive** (vous détectez avant l'impact) change radicalement la gestion d'infrastructure.

## Le Problème : La Détection Tardive

Avant Zabbix, notre équipe découvrait les problèmes quand les utilisateurs appelaient. Résultat :

- **Temps de détection** : 45 minutes en moyenne
- **MTTR** : 4 heures
- **Stress des équipes** : mode "firefighting" constant

## Solution : Zabbix en 3 Étapes

### 1. Configuration des Templates
```bash
# Template personnalisé pour serveurs Windows
zabbix_get -s serveur01 -k system.cpu.util
zabbix_get -s serveur01 -k vm.memory.size[pavailable]

# Monitoring des services critiques
zabbix_get -s serveur01 -k service_state[W3SVC]
zabbix_get -s serveur01 -k net.tcp.service[ssh]
```
