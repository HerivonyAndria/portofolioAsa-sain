# Serveur SMTP Haute Performance pour Mvola

## Contexte

Après la migration des 30+ entités du groupe Axian vers Microsoft 365, un problème critique est apparu : les comptes de service de **Mvola** (service de paiement mobile) qui envoient quotidiennement des centaines de milliers de notifications transactionnelles dépassaient largement les limites d'envoi imposées par Microsoft 365.

**Problèmes identifiés :**
- Limite Microsoft 365 : 10 000 emails/jour par utilisateur
- Besoin Mvola : 500 000+ emails transactionnels/jour
- Délivrabilité dégradée due aux limitations techniques
- Impossible d'envoyer des campagnes marketing massives

## Objectifs du Projet

1. **Performance** : Support d'au moins 1 million d'emails/jour
2. **Délivrabilité** : Taux de délivrabilité > 95%
3. **Sécurité** : Conformité aux standards anti-spam (DKIM, DMARC, SPF)
4. **Monitoring** : Tracking complet des envois en temps réel
5. **Intégration** : Interface transparente avec les systèmes existants de Mvola
