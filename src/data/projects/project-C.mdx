# Migration Unifiée vers Microsoft 365

## Contexte

Le groupe Axian, composé de 30+ entités (Mvola, Yas, Mixx, Axian Telecom, etc.), utilisait des systèmes de messagerie disparates :
- **Zimbra** : 8 entités, 4 000 utilisateurs
- **Exchange Server 2016** : 15 entités, 7 000 utilisateurs  
- **Microsoft 365 (tenants séparés)** : 7 entités, 4 000 utilisateurs

Cette fragmentation posait plusieurs problèmes critiques :
- **Communication difficile** entre collaborateurs de différentes entités
- **Gestion de sécurité complexe** avec multiples administrateurs
- **Coûts élevés** de licences et de maintenance
- **Absence de collaboration unifiée** (Teams, SharePoint, etc.)

## Objectifs du Projet

1. **Unification** : Fusionner tous les utilisateurs dans un tenant Microsoft 365 unique
2. **Modernisation** : Migrer de Zimbra et Exchange vers Exchange Online
3. **Sécurisation** : Mettre en place une gouvernance de sécurité centralisée
4. **Collaboration** : Déployer Teams et SharePoint pour une collaboration cross-entités
5. **Rebranding** : Unifier l'identité des entités Axian-Telecom vers Yas et Mixx
