# Supervision Infrastructure avec Zabbix

## Contexte

Les 30+ entités du groupe Axian hébergeaient leurs infrastructures dans le datacenter de Stellar-ix sans outil de monitoring unifié. 
Les incidents étaient détectés de manière réactive par les appels des clients, et les équipes support travaillaient sans visibilité 
sur la santé des systèmes (réseau, serveurs, firewall). Le temps moyen de résolution (MTTR) était élevé et les coupures impactaient 
15 000+ utilisateurs.

## Objectifs du Projet

1. **Monitoring Proactif** : Détecter les incidents avant qu'ils n'impactent les utilisateurs
2. **Centralisation** : Unifier la supervision de toutes les entités sur une seule plateforme
3. **Automatisation** : Configurer des alertes automatiques et des tableaux de bord en temps réel
4. **Intégration** : Monitorer aussi bien l'infrastructure on-premise que les services cloud (M365)

## Architecture Technique

### Stack Technologique
- **Zabbix 7.0 LTS** : Serveur principal avec base de données PostgreSQL
- **Agents Zabbix** : Déployés sur 200+ serveurs Windows et Linux
- **SNMP Monitoring** : Pour les équipements réseau (PfSense, Meraki, switches)
- **VMware Monitoring** : Intégration vSphere pour la virtualisation
- **Microsoft 365** : Monitoring via API Graph pour Exchange Online, SharePoint, Teams
- **Grafana** : Dashboards avancés pour la direction
- **Slack/Email** : Canaux d'alertes automatiques
